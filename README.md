# Data Science and Analytics Internship

## Overview
This repository contains the projects completed as part of my Data Science and Analytics Internship at DevelopersHub Corporation.

The projects use Python for data exploration, visualization, and machine learning.

## Completed Projects

### 1. Iris Dataset Exploration and Visualization
Exploring the Iris dataset using descriptive statistics and visualizations to understand patterns and relationships between flower features.

### 2. Credit Risk / Loan Prediction
Analyzing loan-related data and developing a classification model to evaluate loan prediction outcomes.

### 3. Customer Churn Prediction
Building a machine learning classification model to predict customer churn and identify important factors influencing customer retention.

### 4. Insurance Cost Prediction
Using Linear Regression to predict medical insurance charges and evaluating model performance using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).
